# Money Lens

## AI-Powered Financial Future Simulator

> See your financial future before you make today's decision.

Money Lens is an AI-powered financial simulation platform that helps users
understand how today's financial decisions could affect their future.

## Core Features

- Financial Time Machine
- Goal Engine
- Reverse Time Machine
- Experiment Lab
- Financial Radar

## Technology Stack

### Frontend
- Next.js
- React
- TypeScript

### Backend
- Python
- FastAPI

### Database
- PostgreSQL

### AI
- Amazon Bedrock

### AWS
- Amazon S3
- Amazon RDS
- AWS Lambda
- Amazon CloudWatch
