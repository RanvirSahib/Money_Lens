# 🗺 Monexa Route Architecture

This directory defines the **file-based routes** for Monexa using [TanStack Router](https://tanstack.com/router).

---

## Route Overview

| Route File | URL Path | Access | Description |
|---|---|---|---|
| `index.tsx` | `/` | Public | Landing page with value proposition, interactive calculator preview, and testimonials |
| `login.tsx` | `/login` | Public | User sign-in with credentials or demo Google provider |
| `create-account.tsx` | `/create-account` | Public | New user onboarding: personal details, baseline financial parameters, and OTP verification |
| `forgot-password.tsx` | `/forgot-password` | Public | Password recovery with 6-digit OTP code dispatch |
| `reset-password.tsx` | `/reset-password` | Public | Password reset confirmation |
| `_authenticated.tsx` | N/A (Layout) | Protected | Route guard: redirects unauthenticated visitors to `/login` |
| `_authenticated.dashboard.tsx` | `/dashboard` | Protected | Main financial overview, net worth timeline, and active scenario summary |
| `_authenticated.accounts.tsx` | `/accounts` | Protected | Financial baseline & balance sheet: monthly income, expenses, SIPs, loans, and subscriptions |
| `_authenticated.spending.tsx` | `/spending` | Protected | Bank statement upload, automated categorization, and discrepancy comparison |
| `_authenticated.goals.tsx` | `/goals` | Protected | Forward and reverse goal tracking (emergency fund, down payments, retirement) |
| `_authenticated.simulations.tsx` | `/simulations` | Protected | What-If simulation playground (major purchases, loan tenures, savings impact) |
| `_authenticated.insights.tsx` | `/insights` | Protected | AI-generated financial health observations and radar risk alerts |
| `_authenticated.profile.tsx` | `/profile` | Protected | User account settings, preferences, and workspace management |

---

## Conventions & Rules
- The root layout is defined in `__root.tsx`.
- `routeTree.gen.ts` is automatically generated by the TanStack Router Vite plugin during development and build. **Do not modify `routeTree.gen.ts` manually.**
